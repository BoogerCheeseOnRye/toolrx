toolrx

the problem

Not every task deserves a frontier model.

01 · cost

Round trip for a one-liner

Asking a large model to add two numbers adds latency, money, and a failure mode where there was none.

02 · correctness

Confident, not correct

General models produce plausible text. For a file listing or a unit conversion, plausible is not a spec.

03 · context

The network is in the loop

Offline labs, air-gapped machines, and privacy-sensitive work can’t depend on a remote endpoint.

Use the biggest hammer for the job. Just don’t use it for a nail you can measure. the toolrx thesis

the idea

Deterministic first. Generative only when asked.

prompt→ normalize→ 11,875 exact commands→ hashed n-gram router→ allow-listed tool→ real result
allow-listed

27 tools, default deny

Arguments are checked against a policy before anything runs. Unknown intent becomes a refusal, not an improvisation.

measured

Confidence and margin

Every route prints a score and the gap to the runner-up, so a weak match is visible instead of hidden.

optional

An LLM you have to ask for

The adapter is off by default. Only an explicit plan or patch request can reach it — never a normal build.

under the hood

A small, inspectable stack.

tokhash.py

Hashed character n-grams. Text statistics, not neural weights. No GPU, no tokenizer dependency.

builder.py

One centroid per tool. Derived from the markdown in knowledge/, rebuildable at any time with --rebuild.

router.py

Cosine score plus margin. Best tool above threshold, otherwise an honest low-confidence refusal.

security.py

Default deny. Argument validation, realpath sandbox, output caps, and no shell interpolation.

web/router.js

Same model in the tab. The Pages build ships a JavaScript port and the command catalog, so static hosting behaves like localhost.

real files

A build is a project, not a chat bubble.

projects/platformer/ index.html styles.css app.js README.md ARCHITECTURE.md engine2d.js // every file is editable, exportable, // and re-bundled into the preview
add double jump → function doubleJump(){ … } spec · 2D side-scroller · platformer · pixel · medium · +double jump changed: app.js, ARCHITECTURE.md, README.md

Eight full-file snapshots per project. undo restores the exact strings that existed before the edit — including removing a 3D engine after a rebuild.

offline by construction

The network is an optional dependency.

installable

One tab, no backend

An installable PWA with a service worker (toolrx-shell-v10). The router, commands, engines, and demos are cached on first visit.

local state

Projects live in the browser

Files, settings, memory, and reading status persist in localStorage. No account, no sync, no analytics.

optional server

Python for the machine parts

The local server adds sockets, /proc, training, and WireGuard. The browser app does not need it.

deliberate exception

One opt-in network path

The LLM adapter is the only feature that can call out. It stays off until you save an endpoint and enable it.

Airplane mode is a supported configuration. not a degraded mode

optional LLM

Generative when it helps. Deterministic when it counts.

01

Off by default

No endpoint and no enabled flag means no request. Normal builds never touch it.

02

Strict schema

One JSON object, an allow-listed genre, and no extra keys. A malformed answer is rejected.

03

Pending diffs

One unified diff, validated hunk-by-hunk. Apply it through the undo snapshot, or discard it untouched.

04

Bounded

HTTPS only (localhost excepted), 8 calls a session, timeout, size cap, and a local key that never enters the cache.

The model can propose. The validator decides. the adapter contract

who it’s for

Built for the tasks that should be boring.

learners

See the route

Confidence, margin, arguments, and the file that changed. No account, no black box.

offline labs

Work disconnected

Planes, trains, air-gapped rooms, and locked-down machines with a browser.

privacy

Keep the text local

The deterministic path never leaves the tab. Shared machines stay shared, not synced.

low-spec

Skip the GPU

A hashed n-gram model and a pattern library run where a model server would not.

Not for: open-ended research, long-form writing, or anything that genuinely needs a general model. Use the right tool.

# Processes tool

Shows the running processes on this machine, their CPU and memory usage.
Use this to see what is running, find heavy processes, or monitor system
load. Read-only monitor tool.

Longer requests and phrasings:
Show the processes that are currently running on this machine.
List all active programs and their process IDs.
What is running right now, and how much CPU is each process using?
Display the process table with command names and resource usage.
Find the heavy processes and show their memory and CPU load.
I want to see every running task on the system.
Report the current programs and their process identifiers.
Show what is running and how loaded the machine is.

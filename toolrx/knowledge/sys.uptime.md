# Uptime tool

Shows how long this machine has been running and the current load average.
Use this when a user asks how long the machine has been up or about system
uptime and load. Read-only monitor tool.

Longer requests and phrasings:
How long has this machine been running since it last booted?
Show the system uptime and the current load average.
Tell me how many days and hours the computer has been up.
What is the uptime of the host, and how loaded is it?
Report the time since boot and the one minute load.
How long has the system been online without a restart?
Display the uptime duration and load figures.
Show how long this machine has been up.

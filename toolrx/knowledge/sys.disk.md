# Disk usage tool

Shows disk space usage and free space on the filesystems of this machine.
Use this when a user asks how much disk space is used or free.
Read-only monitor tool.

Longer requests and phrasings:
How much disk space is used and how much room is left?
Show the disk usage for every mounted volume on this computer.
I need to know if the hard drive is getting full.
Report free and used storage across the mounted file systems.
What is the capacity and remaining space of each filesystem?
Display disk space in gigabytes for all mounts.
Is the disk nearly full, and what is consuming the space?
Show the storage usage summary for this machine.

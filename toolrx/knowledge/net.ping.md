# Ping tool

Checks whether a network host, device, or machine is reachable by sending
ICMP echo packets and waiting for replies. Reports latency and packet loss.
Use this to troubleshoot connectivity to a local machine, gateway, server,
or any reachable host. The target host must be on the operator allowlist.
Read-only monitor tool.

Longer requests and phrasings:
Ping the host and report whether it answers.
Check if the server is reachable over the network.
Send an ICMP echo probe to the allowed host and show the reply.
Test connectivity to the gateway and report the round trip time.
Is that machine reachable, and what is the packet loss?
Probe the network host for latency and reachability.
Check whether this address responds to a ping.
Run a connectivity test against the allowlisted host.

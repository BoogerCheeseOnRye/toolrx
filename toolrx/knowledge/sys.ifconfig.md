# Network interfaces tool

Shows the network interfaces on this machine and their addresses
(IP address, netmask, MAC, up/down state).
Use this when a user wants to see network interfaces, IP addresses, or NIC
status. Read-only monitor tool.

Longer requests and phrasings:
Show the network interfaces on this machine and their IP addresses.
What is the current IP configuration of every network adapter?
List the interface names, addresses, netmask, MAC, and link state.
Display the NIC status and the addresses assigned to each adapter.
I want to see the machine's own interfaces, not a router config file.
Which network adapters are up or down on this computer?
Show the local interface addresses and hardware addresses.
Report the current link state of each network interface.

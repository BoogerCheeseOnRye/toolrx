# Clear all modules tool

Stops and removes every active live monitoring or interval module at once,
clearing all pinned tracker widgets from the chat.
Use this when the user wants to turn everything off: "stop all modules",
"stop everything", "clear all the trackers", "turn off all the live
monitors", "kill all the modules", or "close all widgets".

Longer requests and phrasings:
Clear the list of finished modules and remove their old records.
Forget all of the stopped background monitors and tidy the list.
Remove the completed module entries and reset the monitor history.
Wipe the stored module records now that they have finished.
Clear all modules and remove every pinned widget at once.
Reset the whole module list, including completed entries.
Delete the saved history of stopped monitors.
Turn off everything and clear all tracker records.

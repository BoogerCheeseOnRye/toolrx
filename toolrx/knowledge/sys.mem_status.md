# System memory status tool

Reports how much memory is in use, how much is free, and the total amount
of system memory. This reads the everyday system file /proc/meminfo.
Use this when a user asks how much memory, RAM, or memory usage the machine
has, like "how much memory is free" or "check RAM usage".

Longer requests and phrasings:
How much free memory does this machine have right now?
Tell me the RAM usage, the used amount, and the total physical memory.
I need to know if the computer is running low on memory at the moment.
Show me a summary of memory and swap currently in use.
What is the available memory according to the system information?
Report the memory pressure and how much RAM is left.
Display memory usage from the kernel's meminfo data.
How much of the system memory is occupied and how much is free?

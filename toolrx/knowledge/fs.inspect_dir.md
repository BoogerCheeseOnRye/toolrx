# Inspect directory tool

Browses a folder and then opens and prints the text contents of one file
inside it. Combines a directory listing with reading a chosen file so you
can look at what is in a folder and immediately dump the text of a file.
Use this when the user wants to see a folder and then read the contents of
a file within it, for example inspect the folder then print the contents of
the changelog. Read-only tool; never writes.

Longer requests and phrasings:
Inspect this directory and also read the optional file inside it.
Look inside the folder and open the named file that sits within it.
List the directory contents and show the contents of one file inside.
Examine this folder with the extra file included in the report.
Browse the directory, then print the text of a chosen file within it.
Combine a folder listing with a read of one file in that folder.
Show the directory and dump one file that it contains.
Inspect the folder and the contents of the file inside it together.

This tool always combines two actions: first a folder listing, then reading one
chosen file inside that same folder. The optional file is what makes it inspect
rather than a plain listing. Look for requests that say inspect the directory
and also read the file inside, browse the folder and open the file within,
folder plus one file contents, or list the directory and dump a specific file
inside it. If only a folder listing or only one file is requested, this is not
the right tool.

# Stop module tool

Stops a live monitoring or interval module and removes its pinned widget.
Use this when the user wants to end or close a module they started, like
"stop the memory module", "close that disk widget", "turn off the live
monitor", or "stop tracking that". Needs the module's id.

Longer requests and phrasings:
Stop the background monitor that is currently running.
Cancel the periodic watcher that was started earlier.
End the module with the id shown in the list of running monitors.
Shut down one repeating background task, not all of them.
Turn off that single live widget and remove it from chat.
Halt the specific tracker identified by this module id.
Close just this monitor and leave the others running.
Stop one named interval module for me.

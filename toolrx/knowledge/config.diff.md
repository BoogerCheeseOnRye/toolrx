# Config diff tool

Compares a current configuration file against a proposed one and shows
exactly what differs between them, so you can review a change before you
apply it manually.
Use this when the user wants to compare a current config against a proposed
version, show the diff, or review what would change. Needs a pair of file
paths to compare, like "compare builder.py with cli.py", "diff two files",
"show the differences between X and Y", or "what changed between these
files". This tool is dry run only and never writes, edits, or
changes any file on disk. Read-only tool.

Longer requests and phrasings:
Compare these two config files and show the differences between them.
Diff the first and second configuration file so I can see what changed.
Tell me how the two settings files differ line by line.
Show a unified difference between the old config and the new config.
Review the proposed configuration against the current one.
What would change if I replaced the current file with the proposed file?
Compare a pair of file paths and print only the changed lines.
Show me a side by side view of the differences between two files.

# Listening sockets tool

Lists the TCP/UDP sockets that are listening on this machine and which
ports are open and in use by which process.
Use this to see open ports, listening services, or active connections.
Read-only monitor tool.

Longer requests and phrasings:
Show the active network connections and listening sockets on this host.
What ports are currently listening and which connections are established?
List the TCP and UDP sockets that are open right now.
Display the socket table with local addresses and ports.
Which services are listening, and which processes own those ports?
Show me the network statistics and the current connection table.
I want to see the open ports and established TCP connections.
Report every listening endpoint on this machine.
